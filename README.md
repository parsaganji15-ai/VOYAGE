# VOYAGE — Discover the World

**VOYAGE** is a responsive travel website designed to help users explore destinations, discover travel experiences, and plan their next journey.

The project focuses on modern UI design, responsive layouts, and interactive front-end functionality using HTML, CSS, and JavaScript.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Mobile navigation menu
- Interactive travel search form
- Popular destinations section with category filters
- Destination details modal
- Travel planner modal with form validation
- Travel experiences section
- Featured trips section
- Why Choose Us section
- Newsletter subscription with local storage
- Interactive FAQ accordion
- Responsive footer

## Getting Started

1. Download or clone this repository.
2. Open the project folder.
3. Open HTML/index.html in your browser.

No additional package installation is required.

## Important Notes

- This project is a front-end demonstration.
- Travel search and travel planner forms do not connect to a booking backend.
- Newsletter subscriptions are stored locally in the browser using `localStorage`.
- No real payments or reservations are processed.
